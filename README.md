# AU Cyber Brief

Public archive of the AU Cyber Brief: short daily cyber security briefings with an Australian focus,
published each weekday morning (Perth time), plus periodic Intel reports on the patterns across them.

| Where | What |
| --- | --- |
| [`briefings/daily/`](briefings/daily/) | The daily briefs, one file per weekday (`YYYY/YYYY-MM-DD.md`) |
| [`intel/`](intel/) | Intel reports (monthly, quarterly, yearly), each as Markdown and PDF |

Briefings summarise reporting in our own words and link to the original sources. Intel reports count
patterns across the briefs and cite the dates each finding rests on.

To get the brief on Signal, message the brief bot and send `HELP`.
