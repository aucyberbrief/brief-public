# Daily brief · Thu 19 Nov 2026

## Australia
**Optimizely skimmer reached Vodafone, HSBC Australia, Rest Super and other Australian sites.** iTnews reports that the code injected through Optimizely Web Experimentation ran on Australian sites including Vodafone Australia, TPG Telecom, HSBC Australia, Rest Super, Betashares, Compare Club and Levi's Australia, from 3:21pm AEDT on Monday until about 8:10am Tuesday. It captured card details, cookies and screenshots, swapped crypto wallet addresses and sent unpatched iPhones to exploit kits. Optimizely says attackers abused a flaw in its account signup flow, which it has fixed; TPG has paused Optimizely on Vodafone's site. Customers who paid on affected sites during that window should watch their card statements. Organisations using Optimizely should check snippet history and review third-party script controls.

## Vulnerabilities and advisories
**Java4Shell: patch Java now for a flaw that enables pre-login code execution in Jira, Jenkins and more.** CVE-2026-114938, in the Base64 decoder of Java 17.0.6 and later, can let unauthenticated attackers run code on Keycloak, Jira, Confluence, Artifactory, Jenkins and PingFederate under default settings, on Intel and AMD servers with AVX-512 VBMI. Oracle and OpenJDK have released fixes, Amazon Corretto is patched and Red Hat is preparing builds. CISA urges immediate patching; no attacks are reported yet. Update every JDK and JRE, including those bundled inside applications.
Sources: [The Hacker News](https://thehackernews.com/2026/11/java4shell-cve-2026-114938-enables-pre.html), [BleepingComputer](https://www.bleepingcomputer.com/news/security/critical-java4shell-flaw-allows-rce-attacks-on-major-java-applications/), [Cyber Daily](https://www.cyberdaily.au/security/14457-patch-now-cisa-oracle-and-experts-recommend-urgent-action-over-critical-java-17-rce-vulnerability), [NCSC NZ](https://www.ncsc.govt.nz/alerts/cve-2026-114938-affecting-openjdk/)

**NGINX2Root: critical NGINX flaws allow code execution over HTTP/2.** F5 has fixed five critical NGINX flaws; the worst, CVE-2026-123007, present since 2015, lets an unauthenticated attacker run code on servers with HTTP/2 enabled, and researchers chained it with an unpatched Linux kernel bug to get root. Proof-of-concept code is public. Upgrade to NGINX 1.31.9 or 1.30.7 (or the fixed NGINX Plus builds), or turn off HTTP/2 until you can.
Sources: [The Hacker News](https://thehackernews.com/2026/11/10-year-old-nginx-http2-flaw-lets.html), [iTnews](https://www.itnews.com.au/news/nginx-servers-rootable-through-critical-flaws-unpatched-linux-kernel-bug-630447?utm_source=feed&utm_medium=rss&utm_campaign=iTnews+Security+feed), [Sophos](https://www.sophos.com/en-us/blog/patches-released-for-critical-nginx2root-vulnerabilities)

**Apache Roller flaw exploited without login.** CVE-2026-129448 lets unauthenticated attackers run code through Roller's XML-RPC endpoint in versions 4.0.0 to 6.1.4, and Apache says it's being exploited. Upgrade to 6.1.6, or disable XML-RPC in web.xml; turning it off in the admin interface isn't enough.
Sources: [The Hacker News](https://thehackernews.com/2026/11/critical-apache-roller-rce-flaw-under.html), [BleepingComputer](https://www.bleepingcomputer.com/news/security/apache-warns-of-roller-rce-vulnerability-exploited-in-attacks/)

**CISA flags exploited flaws in LiteLLM, REDCap, Synology DSM and Apache Axis.** The four additions include CVE-2026-40217 in the LiteLLM AI gateway and CVE-2026-90817 in REDCap, widely used for research data in universities and hospitals. Patch these, and keep LiteLLM off the open internet.
Sources: [CISA](https://www.cisa.gov/news-events/alerts/2026/11/18/cisa-adds-four-known-exploited-vulnerabilities-catalog)

## Incidents and threats
**Microsoft's Agent Framework package on PyPI poisoned with a credential stealer.** Malicious versions 1.26.1 and 1.26.2 of agent-framework, published on 17 November and now quarantined, ran a stealer every time Python started, taking credentials and cloud tokens. Anyone who installed them should rebuild the environment and rotate every credential it could reach.
Sources: [The Hacker News](https://thehackernews.com/2026/11/attackers-compromise-microsofts-agent.html), [BleepingComputer](https://www.bleepingcomputer.com/news/security/microsofts-agent-framework-pypi-package-compromised-to-steal-credentials/)

**Russia's Star Blizzard used one victim's cloud data to breach the next.** Google says the group, which it now calls Cold Relic, used staff directories and identities stolen from one US organisation to impersonate its employees and breach another, then registered rogue MFA devices and passkeys to stay in. Review newly registered MFA methods and passkeys, and treat unexpected requests from known contacts with care.
Sources: [The Hacker News](https://thehackernews.com/2026/11/russian-cold-relic-hackers-use-stolen.html), [The Record](https://therecord.media/russia-cyber-espionage-google), [Infosecurity](https://www.infosecurity-magazine.com/news/russian-star-blizzard-cloud-data/)

**Irish credit unions hit through their IT provider.** Members' data at about 40 Irish credit unions was exposed after an attacker made five million requests against an authorisation flaw at supplier Wellington IT. The provider says it lacks the logs to say whose data was taken.
Sources: [BleepingComputer](https://www.bleepingcomputer.com/news/security/data-breach-impacts-40-irish-credit-unions-in-reported-it-provider-hack/)

**Cloud keys left in public Docker images are used within seconds.** Researchers planting decoy keys in 300 public container images saw the first AWS key used less than eight seconds after publication. Scan images for secrets before pushing, and rotate any key that has ever appeared in one.
Sources: [BleepingComputer](https://www.bleepingcomputer.com/news/security/cloud-keys-leaked-in-docker-hub-images-are-stolen-within-seconds/)
