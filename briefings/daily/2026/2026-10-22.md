# Daily brief · Thu 22 Oct 2026

## Australia
**Patch PHP now: ASD's ACSC issued a critical alert on PHP2Shell.** PHP has released emergency fixes for two critical remote code execution flaws, CVE-2026-109618 and CVE-2026-109619 (CVSS 9.2), which affect PHP-FPM, Apache with mod_php, php-cgi, FrankenPHP and LiteSpeed and reach back to PHP 5. Details and proof-of-concept code leaked before the fixes, and Hadrian, watchTowr, Cloudflare and Patchstack all report exploitation attempts in the wild. ASD's ACSC issued a "Critical Alert: Act Now" telling Australian organisations to find PHP in their environments and patch. Install PHP 8.5.12, 8.4.27, 8.3.36 or 8.2.35 (or a vendor backport for older branches), and isolate internet-facing PHP apps that can't be patched yet.
Sources: [Cyber Daily](https://www.cyberdaily.au/security/14334-critical-alert-aussie-cyber-agency-warns-businesses-to-monitor-php-vulnerabilities), [iTnews](https://www.itnews.com.au/news/critical-flaws-strike-php-as-disclosure-embargo-is-broken-629794), [CISA](https://www.cisa.gov/news-events/alerts/2026/10/21/critical-vulnerabilities-php-require-immediate-patching), [NCSC UK](https://www.ncsc.gov.uk/news/critical-security-issue-affecting-php), [BleepingComputer](https://www.bleepingcomputer.com/news/security/php-ships-emergency-patches-for-critical-php2shell-flaws/), [SecurityWeek](https://www.securityweek.com/php2shell-patches-land-as-first-exploitation-attempts-hit-sensors/), [The Record](https://therecord.media/php-script-vulnerabilities-warnings)

**SafePay ransomware has hit more than 600 critical infrastructure organisations, including in Australia.** A joint advisory from CISA, the FBI, the US Secret Service and German and UK agencies says the group, active since August 2024, has hit businesses and critical infrastructure in North America, South America, Europe and Australia. SafePay gets in through exposed credentials, password brute-forcing and VPN and edge-device flaws, then deletes shadow copies and resets backup storage. Enforce MFA, restrict admin tools and patch VPNs and firewalls on the KEV list first.
Sources: [CISA](https://www.cisa.gov/news-events/cybersecurity-advisories/aa26-293a), [BleepingComputer](https://www.bleepingcomputer.com/news/security/cisa-and-fbi-safepay-ransomware-has-hit-over-600-critical-infrastructure-organizations/), [Infosecurity](https://www.infosecurity-magazine.com/news/safepay-compromised-critical/)

## Vulnerabilities and advisories
**Eight eMudhra intermediate CA certificates had trivially recoverable keys.** Keys generated in an April 2025 ceremony were small enough to recover almost instantly, letting anyone forge trusted certificates for any domain. Firefox, Chrome and Apple now block the certificates, and Mozilla and Chrome are removing trust in eMudhra's root. Software with its own certificate store, such as Go programs (CVE-2026-111943), containers, origin servers and mutual TLS setups, may need manual updates.
Sources: [BleepingComputer](https://www.bleepingcomputer.com/news/security/mozilla-google-apple-block-compromised-emudhra-ca-certificates/), [iTnews](https://www.itnews.com.au/news/cloudflare-warns-fixing-botched-emudhra-certs-goes-beyond-browsers-629804), [Cisco Talos](https://blog.talosintelligence.com/compromised-intermediate-certificates/), [The Hacker News](https://thehackernews.com/2026/10/eight-emudhra-ca-keys-compromised.html)

**GitLab fixes a CVSS 10 flaw reaching back to 2014.** CVE-2026-110264 can let an unauthenticated attacker run code on self-managed GitLab servers from version 7.0 onward. Instances patched on 12 October are vulnerable again. GitLab reports no exploitation yet; upgrade self-managed instances to 19.5.1, 19.4.3, 19.3.6 or the fixed release for your branch.
Sources: [The Hacker News](https://thehackernews.com/2026/10/critical-gitlab-flaw-cvss-100-could.html)

**CISA adds Plex2Shell, Siemens Software Center and SiteGuard flaws to KEV.** Six newly listed exploited bugs include the four Plex Media Server flaws chained in Plex2Shell attacks, the Siemens Software Center DLL side-loading flaw (CVE-2026-110936) and a command injection flaw in EG Secure Solutions SiteGuard Server Edition (CVE-2026-106931). US federal agencies must fix three of them by 23 October; apply the same patches.
Sources: [CISA](https://www.cisa.gov/news-events/alerts/2026/10/20/cisa-adds-six-known-exploited-vulnerabilities-catalog), [The Hacker News](https://thehackernews.com/2026/10/cisa-orders-federal-agencies-to-patch.html)

## Incidents and threats
**Stolen UpdraftCentral keys used to backdoor WordPress sites.** TeamUpdraft says attackers reached its customer database on 17 and 18 October, including connection keys for UpdraftCentral, UpdraftVault and UpdraftClone. Patchstack and Nethemba report the keys being used since 18 October to install disguised backdoor plugins and add admin accounts. Update UpdraftPlus to 1.26.13 (free) or 2.26.13 (Premium), delete old UpdraftCentral keys, check for unfamiliar plugins and admins, and rotate storage credentials.
Sources: [BleepingComputer](https://www.bleepingcomputer.com/news/security/stolen-updraftcentral-keys-used-to-backdoor-wordpress-sites/), [The Hacker News](https://thehackernews.com/2026/10/attackers-abuse-updraftcentral-keys-to.html)

**LiteLLM 1.107.0 shipped a credential stealer and backdoor.** Attackers used stolen GitHub tokens from three LiteLLM engineers to publish a malicious release through PyPI and Docker. It harvests cloud tokens, private keys, browser data and AI tool credentials, and polls for further commands. Anyone who installed 1.107.0 should remove it and rotate every secret on that machine.
Sources: [The Hacker News](https://thehackernews.com/2026/10/litellm-compromised-in-supply-chain.html)

**Japanese VPS provider Onamae Desktop Cloud breached.** GMO Internet says attackers installed malicious programs on customer servers, potentially up to 26,739 of them, and it has shut the whole service down. Customers should rotate any secrets stored on those servers and watch for phishing.
Sources: [BleepingComputer](https://www.bleepingcomputer.com/news/security/japans-onamae-desktop-cloud-hacked-up-to-27-000-servers-affected/)

**Hijacked Tor exit relays intercepted SSH logins.** More than 300 Tor exit relays were reconfigured between 1 and 5 October to send SSH traffic to interception servers that captured passwords. The Tor Project removed them by 5 October. Anyone who logged in to SSH with a password over Tor in that window and accepted a new host key should change the password and check the server for compromise.
Sources: [The Hacker News](https://thehackernews.com/2026/10/attackers-hijacked-over-300-tor-exit.html)
