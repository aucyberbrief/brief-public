# Daily brief · Wed 11 Nov 2026

## Australia
**Townsville's Calvary Christian College confirms a cyber incident after a Qilin listing.** The school told Cyber Daily that attackers reached a single system used for permission forms and that no other school systems were affected. Qilin listed the college on its leak site on 5 November and is threatening to publish data. The ACSC and OAIC have been told, and the school will contact those affected. Parents should be wary of messages that quote school permission forms.
Sources: [Cyber Daily](https://www.cyberdaily.au/security/14423-exclusive-townsville-s-calvary-christian-college-investigating-cyber-incident)

**Federal government proposes an AI safety regulator after the Medicare portal incident.** Ministers say forthcoming AI standards legislation will impose mandatory safety obligations, independent model evaluation and rapid incident disclosure on frontier AI companies operating in Australia, enforced by a new regulator with significant penalties. It follows the June incident in which an OpenAI agent accessed files from an older Medicare data portal. Home Affairs has ordered a government-wide stocktake of systems by March to find weaknesses AI agents could exploit.
Sources: [iTnews](https://www.itnews.com.au/news/gov-proposes-ai-safety-regulator-630244?utm_source=feed&utm_medium=rss&utm_campaign=iTnews+Security+feed)

## Vulnerabilities and advisories
**Patch Tuesday fixes an exploited Outlook flaw that leaks NTLM hashes.** Microsoft's November updates fix 1,235 flaws, 66 of them critical, including CVE-2026-124194. That flaw lets a crafted message file make Outlook connect to an attacker's server without the usual warning, exposing the user's authentication hash. Prioritise the Outlook update and block outbound SMB to the internet.
Sources: [BleepingComputer](https://www.bleepingcomputer.com/news/microsoft/microsoft-november-2026-patch-tuesday-fixes-1-235-flaws-outlook-zero-day/), [CISA](https://www.cisa.gov/news-events/alerts/2026/11/10/cisa-adds-six-known-exploited-vulnerabilities-catalog)

**Chrome fixes its eighth exploited zero-day of the year.** Google says an exploit exists in the wild for CVE-2026-125350, a use-after-free in Chrome's XML handling. Update Chrome and other Chromium-based browsers and make sure they restart.
Sources: [BleepingComputer](https://www.bleepingcomputer.com/news/security/google-patches-eighth-chrome-zero-day-exploited-in-attacks-this-year/)

**Barracuda Email Security Gateway flaws now exploited for root.** Barracuda says attackers are exploiting CVE-2026-116606 and CVE-2026-111560, patched a week ago, against a small number of customers; attacks need access to the admin interface. CISA has added both to its exploited list, along with the Cisco BroadWorks flaw used in the AI-agent telco intrusion. Check that the patch is applied, turn automatic patching back on, and restrict the admin interface to trusted networks.
Sources: [BleepingComputer](https://www.bleepingcomputer.com/news/security/hackers-exploit-barracuda-email-security-gateway-flaws-to-get-root-access/), [CISA](https://www.cisa.gov/news-events/alerts/2026/11/10/cisa-adds-six-known-exploited-vulnerabilities-catalog)

**Xen Orchestra authentication bypass exploited to take over virtualisation hosts.** Vates says attackers are exploiting a flaw (VSA-2026-062, no CVE yet) that lets a crafted cookie log in as an existing user with admin rights, leading to root on XCP-ng hosts. Update to Xen Orchestra 6.9.1 or 6.10.0, or restrict the interface to a management network, and check for connections to the attacker infrastructure in Vates' advisory.
Sources: [BleepingComputer](https://www.bleepingcomputer.com/news/security/critical-xen-orchestra-auth-bypass-flaw-exploited-to-hijack-vm-servers/)

**SAP fixes four maximum-severity flaws in NetWeaver, Gateway and Web Dispatcher.** The fixes include flaws Onapsis calls ICM2SHELL and PROXYGATE, which allow remote code execution without an SAP user or password against network-facing components. Apply SAP's November patches, starting with internet-facing Web Dispatcher and ICM.
Sources: [BleepingComputer](https://www.bleepingcomputer.com/news/security/sap-patches-four-maximum-severity-security-vulnerabilities/), [The Hacker News](https://thehackernews.com/2026/11/sap-patches-four-cvss-100-flaws.html)

**Git flaw lets a malicious repository run code on a recursive clone.** CVE-2026-111760 lets a crafted repository plant hooks through a submodule when cloned with submodules. Update Git to 2.56.1 or the fixed release for your series, and update tools that bundle their own Git; GitHub has patched its hosted services.
Sources: [The Hacker News](https://thehackernews.com/2026/11/git-patches-flaw-that-lets-malicious.html)

**N-able N-central still offline; scanning for the published exploits seen.** Sophos says N-able has seen scanning linked to the published exploit code and there are third-party reports of exploitation, though N-able and Sophos haven't confirmed any. On-premises customers should keep servers offline until the hotfix arrives.
Sources: [Sophos](https://www.sophos.com/en-us/blog/n-able-issues-advisory-on-critical-vulnerabilities), [The Hacker News](https://thehackernews.com/2026/11/n-able-takes-hosted-n-central-offline.html)

## Incidents and threats
**Turla's new Cereal malware reads government email inside Exchange.** ESET says Russia's Turla, which it links to the FSB, used the toolset at government bodies in Kazakhstan and Romania, injecting into Exchange's transport process to collect emails with attachments exchanged with NATO and EU contacts. It used the Exchange server itself as its only control point. Government Exchange operators should look for unexpected code in EdgeTransport and unusual requests to Exchange web paths.
Sources: [BleepingComputer](https://www.bleepingcomputer.com/news/security/turla-hackers-use-new-ceral-malware-to-spy-on-govt-exchange-servers/), [The Hacker News](https://thehackernews.com/2026/11/russian-turla-hackers-use-new-cereal.html), [Infosecurity](https://www.infosecurity-magazine.com/news/turla-cereal-exchange-email/)

**Fireworks AI breach widens to customer datasets and models.** The AI infrastructure provider says attackers who reached its development machines through a third-party cloud provider in late October also accessed account and billing data, secrets, datasets and incomplete models for a limited set of accounts. Customers should rotate keys and secrets held on the platform.
Sources: [The Hacker News](https://thehackernews.com/2026/11/fireworks-ai-breach-widens-to-expose.html), [The Record](https://therecord.media/ai-company-fireworks-says-hackers-stole-data-in-oct-attacks), [BleepingComputer](https://www.bleepingcomputer.com/news/security/fireworks-ai-discloses-new-breach-after-cloud-provider-hack/)
