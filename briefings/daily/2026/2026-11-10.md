# Daily brief · Tue 10 Nov 2026

## Australia
**Carmaker's app hid an admin login that let researchers unlock and start cars; Australian site easier to breach.** Researchers Shubham Shah and Sam Curry found that two car brands' customer login systems had an administrator console still using its default password, which they reached by tricking the site's edge protection. Starting from a number plate, they could take over customer accounts and remotely unlock and start connected cars. They told iTnews one carmaker's Australian site was easier to exploit than its US site because of a weaker web application firewall. The flaws were fixed within about two hours. Identity platform operators should remove or lock down built-in admin consoles and default credentials.
Sources: [iTnews](https://www.itnews.com.au/news/admin-creds-left-in-carmaker-app-opened-doors-to-vehicles-630222?utm_source=feed&utm_medium=rss&utm_campaign=iTnews+Security+feed), [The Hacker News](https://thehackernews.com/2026/11/default-adminadmin-server-password.html)

## Vulnerabilities and advisories
**N-able takes N-central offline after a researcher publishes 30+ unpatched flaws.** A researcher released proof-of-concept exploits for more than 30 alleged zero-days in the N-central remote management platform, including an unauthenticated chain to code execution and to creating a rogue administrator account. N-able has taken hosted N-central offline in all regions and told on-premises customers to shut their servers down until a hotfix is ready; it says it has seen no exploitation. MSPs on N-central should keep servers offline, follow N-able's updates and review admin accounts once they're back.
Sources: [BleepingComputer](https://www.bleepingcomputer.com/news/security/n-able-takes-cloud-platform-offline-after-30-plus-zero-days-published/)

**SSHole exploitation spreads; CISA adds it to its exploited list.** GreyNoise recorded successful attacks on CVE-2026-123158 from 7 November, with attackers reading password hashes and SSH keys, querying cloud metadata services and, in one case, installing a remote access agent as root. CISA added the flaw to its catalogue on 9 November. Patch OpenSSH on Alpine and other musl-based systems now, or set PasswordAuthentication to no, and check for unexpected authorized_keys changes.
Sources: [BleepingComputer](https://www.bleepingcomputer.com/news/security/hackers-exploit-sshole-openssh-flaw-to-breach-linux-systems/), [CISA](https://www.cisa.gov/news-events/alerts/2026/11/09/cisa-adds-four-known-exploited-vulnerabilities-catalog)

**CISA also flags exploited flaws in GPUStack, FreeSWITCH and IBM Aspera Faspex.** The same update added CVE-2026-102895 (GPUStack authentication), CVE-2026-116779 (SignalWire FreeSWITCH code injection) and CVE-2026-123218 (IBM Aspera Faspex authorisation). Patch these if you run them, especially internet-facing file transfer and VoIP servers.
Sources: [CISA](https://www.cisa.gov/news-events/alerts/2026/11/09/cisa-adds-four-known-exploited-vulnerabilities-catalog)

## Incidents and threats
**France blames Iran for the supermarket refrigeration attacks, which caused 15 fires.** France's foreign ministry attributed the October attacks on about 700 retail sites to Shahid Kaveh, a unit linked to Iran's Revolutionary Guard. It says they caused tens of millions of euros in losses and at least 15 fires. French investigators also linked attacks on equipment at small hydroelectric sites to the same campaign. Operators of refrigeration and other building controllers should remove them from the internet.
Sources: [BleepingComputer](https://www.bleepingcomputer.com/news/security/france-blames-iranian-hackers-for-supermarket-attacks-that-sparked-fires/), [The Record](https://therecord.media/france-blames-iran-for-fridge-cyberattacks)

**Attacker used Qubole's trusted AWS access to raid customer accounts.** Wiz says an attacker used credentials for the AWS account Qubole's data platform uses to assume roles in several customers' accounts between 14 and 26 October and stole secrets and data. Most of the roles were unused but still trusted Qubole. Anyone who has ever connected Qubole should check CloudTrail from 1 October for AssumeRole calls from Qubole's account coming from outside AWS, and remove roles they no longer need.
Sources: [The Hacker News](https://thehackernews.com/2026/11/hackers-exploit-quboles-trusted-aws.html)

**Fake "security audit" workflow steals secrets from tens of thousands of GitHub repositories.** Socket says two compromised accounts pushed a GitHub Actions workflow posing as a security audit to repositories they could write to; it sends repository credentials to an attacker's server. Check recent commits that add or change workflows and rotate any secrets the workflows could read.
Sources: [Infosecurity](https://www.infosecurity-magazine.com/news/supply-chain-attack-thousands/)

**Swarm developer tools hijacked to steal crypto wallet keys.** Attackers used Ethersphere's own release automation to publish malicious bee-js 13.3.0 and Swarm Desktop 0.56.2, which steal node wallet keys and install a backdoor on Windows, macOS and Linux. Both were withdrawn, but removal doesn't clean infected machines. Anyone who installed them should rebuild the machine and move funds to new keys.
Sources: [The Hacker News](https://thehackernews.com/2026/11/hackers-compromise-etherspheres-bee-js.html)

**Jailbroken AI agent ran a two-week intrusion at a European telco.** Malbear Labs found an attacker's exposed working directory showing a jailbroken agent built on a DeepSeek model breaking into a telecom provider through a patched Cisco BroadWorks flaw (CVE-2026-20320), then into 13 organisations hosted on its infrastructure using old Liferay and JBoss flaws. The operator mostly just told it to carry on. Old, unpatched flaws on internal hosts are now cheap for automated attackers to chain.
Sources: [Infosecurity](https://www.infosecurity-magazine.com/news/operation-snowball-ai-telecom/)

**German web host breached through its AI assistant connector.** Mittwald says attackers exploited a flaw in the Model Context Protocol server customers use to connect AI assistants to its hosting platform, compromising 56 customer projects over eight undetected days. Treat AI assistant connectors as internet-facing attack surface: patch them, limit their permissions and log their use.
Sources: [The Record](https://therecord.media/cyberattack-germany-ai-mittwald)
