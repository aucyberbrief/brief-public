# Daily brief · Tue 27 Oct 2026

## Australia
**ASD releases its Annual Cyber Threat Report 2025-26.** ASD's seventh annual report warns of continuing threats from state actors and cybercriminals. It urges organisations to take five actions: log all cyber events, replace legacy technology, manage supply chain risk, strengthen AI preparedness and prepare now for quantum computing. The government says ASD's partnership program has grown past 149,500 partners. Boards and security teams should check their plans against the five actions.
Sources: [Minister for Defence](https://www.minister.defence.gov.au/media-releases/2026-10-26/albanese-government-works-public-private-sector-organisations-strengthen-cyber-resilience)

**Fortinet critical updates: the ACSC alert now names products.** The ACSC's 23 October critical alert covers critical and high-severity flaws that Fortinet says its AI-assisted testing found in FortiOS, FortiManager, FortiAnalyzer and FortiMail. Fortinet urges immediate upgrades and plans to publish more detail on 10 November. Experts quoted by Cyber Daily expect exploitation soon. Patch now, or take exposed management interfaces offline or restrict access to them.
Sources: [Cyber Daily](https://www.cyberdaily.au/security/14348-act-now-acsc-warns-of-critical-vulnerabilities-in-fortios-fortimanager-fortianalyzer-and-fortimail), [ASD's ACSC](https://www.cyber.gov.au/alert/critical-vulnerabilities-in-fortinet-products)

**Bathurst RSL confirms cyber incident after Qilin listing.** The NSW club says it engaged specialists, contained the incident and is contacting people whose personal information was involved. It says its gaming and membership systems were not affected. Qilin listed the club on its leak site on 22 October.
Sources: [Cyber Daily](https://www.cyberdaily.au/security/14349-exclusive-bathurst-rsl-says-cyber-incident-contained-after-qilin-ransomware-attack)

**OAIC: more large breaches affecting Australians.** Notifiable data breaches rose slightly to 667 in the first half of 2026. Breaches affecting more than a million people jumped from four to 11. Malicious or criminal attacks were the main cause, and health providers reported the most breaches, followed by education. The OAIC urges organisations to hold less personal data.
Sources: [Cyber Daily](https://www.cyberdaily.au/security/14350-stat-dump-data-breaches-impacting-aussies-continue-to-rise-oaic-says)

## Vulnerabilities and advisories
**PHP2Shell remote code execution confirmed in the wild.** A Perplexity researcher's honeypots recorded working remote code execution against Apache mod_php on an unpatched PHP 8.4 build, and Expel's Marcus Hutchins called it the strongest confirmation so far. SecurityWeek reports attacks moving from probes to working shells. Any PHP server not yet on 8.5.12, 8.4.27, 8.3.36 or 8.2.35 should be treated as at risk.
Sources: [BleepingComputer](https://www.bleepingcomputer.com/news/security/php2shell-security-flaws-now-sucessfully-exploited-in-the-wild/), [SecurityWeek](https://www.securityweek.com/php2shell-exploitation-moves-from-probes-to-working-shells/)

**Emergency patches for the Brotli flaw spread to .NET, PHP and Python.** Microsoft shipped out-of-band .NET updates for CVE-2026-111497, also called HTTP2Shell or Node2Shell, and PHP issued a second Windows update. The out-of-bounds write in Google's Brotli decoder affects Node.js, Python HTTP clients such as urllib3 and httpx, and anything else that decompresses untrusted Brotli data. Update runtimes and libraries, and rebuild containers.
Sources: [BleepingComputer](https://www.bleepingcomputer.com/news/security/critical-http2shell-brotli-vulnerability-triggers-emergency-patches/), [BleepingComputer](https://www.bleepingcomputer.com/news/microsoft/microsoft-releases-emergency-net-patches-for-critical-brotli-flaw/), [The Hacker News](https://thehackernews.com/2026/10/php-issues-second-windows-security.html), [SecurityWeek](https://www.securityweek.com/node2shell-brotli-flaw-triggers-patching-across-microsoft-node-js-python-packages/)

## Incidents and threats
**Microsoft 365 "token spraying" compromised 97 accounts at 79 organisations.** Huntress tracked a campaign that used an adversary-in-the-middle login page to steal session tokens, then replayed them at scale. The attackers registered their own authenticator apps and fake Entra devices for persistence, and set hidden inbox rules to hide payroll emails. Review newly added MFA methods, registered devices and inbox rules.
Sources: [The Hacker News](https://thehackernews.com/2026/10/microsoft-365-token-replay-attacks.html)

**"Gheist" uses stolen GitHub tokens to dump repository secrets.** Wiz says an automated campaign pushes a workflow on a new "ci-sync-" branch that prints secrets into Actions logs, downloads them and deletes the run. It succeeds in private repositories and on GitHub Enterprise Server. If such branches appear, rotate every secret the repository can read and revoke the token that pushed them.
Sources: [The Hacker News](https://thehackernews.com/2026/10/gheist-uses-stolen-github-tokens-to.html), [Infosecurity](https://www.infosecurity-magazine.com/news/gheist-attackers-abuse-stolen/)

**953 online stores infected with scanner-evading skimmer loader.** Sansec found malicious JavaScript planted in Magento CMS blocks since July 2025, mostly through the PolyShell (CVE-2026-48356) and SessionReaper (CVE-2025-54236) flaws. The code hides from security scanners. Magento merchants should patch, check CMS blocks for unfamiliar scripts and look for web shells in media folders.
Sources: [The Hacker News](https://thehackernews.com/2026/10/hackers-infect-953-online-stores-with.html), [SecurityWeek](https://www.securityweek.com/953-online-stores-infected-in-long-lasting-malware-campaign/)
