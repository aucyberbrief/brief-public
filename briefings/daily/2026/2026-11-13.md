# Daily brief · Fri 13 Nov 2026

## Australia
**Hacker defaces the VCAA website during VCE exams and claims exams were sold.** The Victorian Curriculum and Assessment Authority's site is down after an attacker calling themselves DaggerElite replaced its front page, claiming to have sold exam papers to students and to have compromised external printers. The VCAA says there's no evidence any exams or sensitive data were accessed, calls the claims fabricated and says exams continue as normal. Schools and families should treat offers of "leaked" exams as scams.
Sources: [Cyber Daily](https://www.cyberdaily.au/security/14436-breached-hacker-defaces-vcaa-website-says-exams-sold-to-students)

**Extortion group n0n leaks data it says came from Expedia, including Australian email addresses.** n0n claims to have taken more than a terabyte of Expedia customer and loyalty data and has published an extract with hundreds of thousands of email addresses linked to bookings and loyalty accounts; Cyber Daily found Australian addresses among them. Some of the data may be old, and Expedia declined to comment. Expedia customers should watch for phishing that quotes bookings or loyalty points.
Sources: [Cyber Daily](https://www.cyberdaily.au/security/14440-exclusive-cyber-extortion-group-claims-breach-of-expedia-millions-of-customers-allegedly-exposed)

## Vulnerabilities and advisories
**New N-central exploits work on patched servers; one is already being used.** The researcher behind Able2Shell released 4EverAble2Shell, unauthenticated root code execution on N-central servers with the Legacy API turned on, and Agent2Shell, SYSTEM-level code execution on managed Windows agents. Both work against the 10 November hotfix. Attackers began using 4EverAble2Shell within hours to install cryptocurrency miners, hitting at least 21 servers, 19 of them fully patched. N-able says hosted servers aren't affected. On-premises customers should turn off the Legacy API now and check for unfamiliar processes.
Sources: [BleepingComputer](https://www.bleepingcomputer.com/news/security/new-n-able-4everable2shell-zero-day-exploited-hours-after-poc-released/), [The Hacker News](https://thehackernews.com/2026/11/new-n-central-exploits-work-against.html)

**Unpatched Windows "SignDrop" exploit gives SYSTEM and can switch off EDR.** A researcher published an exploit that abuses Microsoft's 2025 CLFS hardening to gain SYSTEM rights and to defeat antimalware tamper protection. He estimates 80% of Windows installs are affected, and there's no fix yet. Watch for Microsoft's patch and for signs of security tools being disabled.
Sources: [BleepingComputer](https://www.bleepingcomputer.com/news/security/new-windows-signdrop-zero-day-gives-hackers-system-privileges/), [The Hacker News](https://thehackernews.com/2026/11/new-signdrop-zero-day-exploit-turns.html)

**Critical Apache HTTP Server flaw in HTTP/2 allows remote code execution.** CVE-2026-119618, a race condition in mod_http2, affects Apache 2.4.55 to 2.4.70 where HTTP/2 is turned on (it's off by default). Update Apache, or turn off HTTP/2 until you can.
Sources: [BleepingComputer](https://www.bleepingcomputer.com/news/security/apache-http-server-patches-critical-http-2-remote-code-execution-flaw/), [The Hacker News](https://thehackernews.com/2026/11/critical-apache-http2-flaw-could-let.html)

**Citrix fixes 12 NetScaler flaws, including a Console authentication bypass.** Most are critical memory flaws that can crash NetScaler ADC and Gateway in particular configurations; CVE-2026-120869 lets an unauthenticated attacker bypass authentication on NetScaler Console. No exploitation is reported, but NetScaler was attacked heavily in October. Patch this week.
Sources: [The Hacker News](https://thehackernews.com/2026/11/citrix-patches-12-netscaler-and-secure.html)

**Microsoft to distrust all eMudhra roots from 16 November.** After eMudhra's key failures, Microsoft will remove its remaining roots from Windows, Edge and Azure, and eMudhra says Apple will end trust on 30 November. Find and replace any eMudhra-issued certificates before then, or services using them will break.
Sources: [iTnews](https://www.itnews.com.au/news/emudhra-fiasco-widens-eight-more-cas-revoked-microsoft-pulls-trust-630303?utm_source=feed&utm_medium=rss&utm_campaign=iTnews+Security+feed)

## Incidents and threats
**ScreenConnect campaign breaches MSPs and their customers.** Huntress says attackers abused ScreenConnect's Run Command in compromised MSP cloud instances to push rogue remote-access clients to customer machines, reaching at least 288 endpoints at 48 organisations. ConnectWise suspects third-party extensions and has disabled five in about 400 partner environments. MSPs should review Run Command history, installed extensions and admin logins even without alerts.
Sources: [BleepingComputer](https://www.bleepingcomputer.com/news/security/active-screenconnect-attacks-breach-msps-impact-dozens-of-organizations/), [The Hacker News](https://thehackernews.com/2026/11/screenconnect-attacks-target-at-least.html), [The Record](https://therecord.media/connectwise-screenconnect-breaches-third-party-tool)

**4,837 hijacked GitHub accounts used to steal CI secrets.** Aikido says an attacker used stolen credentials to plant a secret stealer in repositories those accounts could write to, then usually reverted it within minutes; it ran in at least 1,806 repositories. Look for a "docs: dependency audit notes" pull request or a wfx-docs branch, and if found, treat every secret your workflows can reach as compromised.
Sources: [The Hacker News](https://thehackernews.com/2026/11/4837-hijacked-github-accounts-ran-ci.html)

**PHP2Shell used to break into Check Point gateways, with a wiper in Israel.** Check Point says attackers exploited PHP2Shell on unpatched Mobile Access portals from 30 October, escalated to root with CVE-2026-123039 and planted backdoors. Against some Israeli organisations they moved on to VMware ESXi and ran a wiper. Patch Check Point gateways for both flaws and hunt for web shells if Mobile Access was exposed.
Sources: [Check Point Research](https://research.checkpoint.com/2026/php2shell-exploitation-on-check-point-gateway/)

## Law enforcement and policy
**Operation Endgame takes down Gootloader, CastleRAT and StealC infrastructure.** Police from nine countries, coordinated by Europol and Eurojust, seized 235 servers and 257 domains and found 6.4 million sets of stolen victim data. Gootloader has long been a route into ransomware attacks.
Sources: [BleepingComputer](https://www.bleepingcomputer.com/news/security/police-dismantles-gootloader-castlerat-stealc-malware-infrastructure/), [The Record](https://therecord.media/european-authorities-take-down-stealic-malware-second-time)
