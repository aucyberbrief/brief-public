# Daily brief · Tue 24 Nov 2026

## Australia
**O'Brien Group Australia listed by LockBit 5.0.** The LockBit 5.0 ransomware group has listed O'Brien Group Australia (obriengroupaustralia.com.au) on its leak site; both ransomware.live and RansomLook show the listing. The company hasn't commented publicly.
Sources: [ransomware.live](https://www.ransomware.live/id/b2JyaWVuZ3JvdXBhdXN0cmFsaWEuY29tLmF1QGxvY2tiaXQ1), [RansomLook](https://www.ransomlook.io//group/lockbit5)

## Vulnerabilities and advisories
**Azure API Management flaw exploited to steal secrets; Norwegian energy firms hit.** Microsoft says a flaw in Azure API Management Classic tiers let attackers reach management functions on instances not set up to its recommended practice and read stored secrets, client secrets, subscription keys and management tokens. It mitigated the flaw on 19 November. Norway's security authority says Equinor and Skagerak Energi were among those targeted. Azure customers using APIM Classic should rotate every credential stored there and check the systems those credentials reach.
Sources: [BleepingComputer](https://www.bleepingcomputer.com/news/security/microsoft-azure-flaw-exploited-to-steal-customers-api-credentials/), [The Record](https://therecord.media/norway-microsoft-cyberattack-equinor)

**ScreenConnect client flaw exploited to hijack MSP technicians' PCs.** Huntress says attackers have sprayed ScreenConnect servers since 20 October with guest "run file" requests exploiting CVE-2026-84869, which lets a guest run a payload on a connecting technician's computer; in one case a technician's PC was taken over in about nine seconds. Make sure every technician runs the patched ScreenConnect client, and check for unexpected batch files and rogue ScreenConnect installs on technician machines.
Sources: [The Hacker News](https://thehackernews.com/2026/11/hackers-exploit-critical-screenconnect.html)

**N-able Mail Assure flaw found in breach investigation, and now on CISA's exploited list.** CVE-2026-134624 let an API user make Mail Assure and SpamExperts servers connect to internal systems; N-able fixed it and restored dashboards on Saturday. CISA has added it, along with the MONAI Label flaw that AI agents exploited, to its exploited list. MSPs using these services should review API keys and admin activity.
Sources: [The Hacker News](https://thehackernews.com/2026/11/n-able-discloses-critical-mail-assure.html), [CISA](https://www.cisa.gov/news-events/alerts/2026/11/23/cisa-adds-two-known-exploited-vulnerabilities-catalog)

**Old ASP.NET anti-CSRF library exploited for code execution.** Mandiant found attackers exploiting CVE-2026-131914 in Idunno.AntiCsrf, an abandoned 2008 library for ASP.NET WebForms, with a single unauthenticated request. There's no fix; search your WebForms apps for Idunno.AntiCsrf.dll and remove it.
Sources: [The Hacker News](https://thehackernews.com/2026/11/hackers-exploit-critical-aspnet-anti.html)

**"Ruby2Shell" flaw: patch Ruby before scanning starts.** CVE-2026-132825, a heap overflow in Ruby's string case conversion, can allow code execution in some scenarios; it may sit in self-hosted products such as GitLab, GitHub Enterprise Server and Mastodon. watchTowr expects scanning within days. Update to Ruby 3.3.14, 3.4.13 or 4.0.10 and apply vendor updates for bundled copies.
Sources: [Cyber Daily](https://www.cyberdaily.au/security/14479-2shell2soon-experts-expect-scanning-of-new-ruby2shell-flaw-within-days)

## Incidents and threats
**New Zealand Defence Force website down after a provider breach.** An intruder got into the NZDF's website provider on 20 November, possibly exposing names and emails of people registered in the Force4Families discount scheme. Registered users should watch for phishing.
Sources: [Cyber Daily](https://www.cyberdaily.au/security/14478-new-zealand-defence-force-website-remains-down-days-after-data-breach-disclosure)

**Korea's KEPCO breach exposes 1.5 million people.** The state power company says attackers reached its billing platform and procurement system, exposing customer, employee and contractor data.
Sources: [BleepingComputer](https://www.bleepingcomputer.com/news/security/south-koreas-power-giant-kepco-confirms-data-breach-impacting-15-million/)

**Austrian Foreign Ministry website breached through a provider.** Hackers accessed names and official contact details of staff in Vienna and at diplomatic missions abroad on 12–13 November. Diplomats' contact lists are useful for targeted phishing.
Sources: [The Record](https://therecord.media/austrian-foreign-ministry-says-website-hacked)

## Law enforcement and policy
**US moves to forfeit US$1.1 billion stolen from Binance by North Korea.** The Justice Department says it has helped freeze, seize or return more than US$2.9 billion of the roughly US$6 billion stolen in the Binance hack.
Sources: [Justice Department](https://www.justice.gov/opa/pr/united-states-files-action-recover-more-1-billion-cryptocurrency-assets-stolen-north-korean)
