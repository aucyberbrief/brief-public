# Daily brief · Fri 20 Nov 2026

## Australia
**Hacker offers Golf Australia reader data for sale.** A forum user calling themselves LeonardoBF claims to have broken into the Zoho CRM of Golf Australia magazine, published by NextMedia, and is selling access and data including reader names, emails, phone numbers, subscriber records and news tips. The publisher hadn't responded to Cyber Daily. Readers should be wary of unexpected calls about cryptocurrency or investments.
Sources: [Cyber Daily](https://www.cyberdaily.au/security/14464-exclusive-golf-australia-reader-data-allegedly-offered-for-sale-on-hacking-forum)

## Vulnerabilities and advisories
**VMware vCenter zero-day used by a China-linked group for two months; patch now.** Broadcom has fixed CVE-2026-123890 (CVSS 9.8), an authentication bypass in vCenter's directory service that gives an attacker an administrator session. Google says the suspected China-nexus group ARMORY CASTLE exploited it as a zero-day, then ran commands and took the directory database. It affects vCenter 8.0, 9.0 and 9.1, including the builds inside Cloud Foundation; older versions should be presumed affected. Broadcom calls this an emergency change. Patch now, keep vCenter off untrusted networks and check for unexpected administrator sessions.
Sources: [The Hacker News](https://thehackernews.com/2026/11/critical-vmware-vcenter-flaw-cvss-98.html), [Google Threat Intelligence](https://cloud.google.com/blog/topics/threat-intelligence/armory-castle-exploits-vsphere/)

**PHP fixes seven critical flaws, including one left over from PHP2Shell.** The PHP project released fixes for 18 flaws across all supported versions, seven critical, some allowing remote code execution under particular configurations; SecurityWeek says one completes the incomplete PHP2Shell fix. Given how fast PHP2Shell was exploited last month, update to the latest 8.2, 8.3, 8.4 or 8.5 release now, including PHP bundled in appliances.
Sources: [The Hacker News](https://thehackernews.com/2026/11/php-fixes-7-critical-flaws-including.html), [BleepingComputer](https://www.bleepingcomputer.com/news/security/php-security-updates-fix-18-flaws-including-critical-rce-bugs/), [Infosecurity](https://www.infosecurity-magazine.com/news/php-releases-patches-fix-18/), [SecurityWeek](https://www.securityweek.com/php-patches-seven-critical-rce-vulnerabilities/)

**Drupal fixes a critical installer flaw that allows site takeover.** CVE-2026-132165 lets anonymous users abuse Drupal's installer to reinstall a site, leading to takeover or code execution. Drupal warns exploits may appear quickly. Upgrade to 10.6.22, 11.3.22 or 11.4.13, and make sure the web server can't write to settings.php.
Sources: [BleepingComputer](https://www.bleepingcomputer.com/news/security/drupal-patches-critical-rce-flaw-warns-exploits-may-surface-quickly/), [The Hacker News](https://thehackernews.com/2026/11/drupal-patches-critical-installer-flaw.html)

**ASUS fixes a maximum-severity flaw in Control Center Express.** A hard-coded key (CVE-2026-114202, CVSS 10) lets an unauthenticated attacker forge an admin token for the console that manages fleets of ASUS business PCs. Update to 1.7.29.
Sources: [BleepingComputer](https://www.bleepingcomputer.com/news/security/asus-warns-of-critical-hard-coded-key-flaw-in-control-center-express/)

**Cisco Expressway flaw exploited soon after a public exploit.** SecurityWeek reports attackers used CVE-2026-76466 against clustered Expressway devices shortly after proof-of-concept code appeared. Patch Expressway and restrict its management interfaces.
Sources: [SecurityWeek](https://www.securityweek.com/hackers-exploit-cisco-expressway-vulnerability-soon-after-poc-release/)

## Incidents and threats
**N-able's Mail Assure and SpamExperts cloud breached.** N-able says attackers got into a server in its hosted Mail Assure and SpamExperts platform, which is why management portals, APIs, quarantine and logs have been offline in all regions since 16 November; mail filtering continues. It says there's no evidence so far of customer data or mailbox access. MSPs using these services should follow N-able's partner notices and watch for unusual mail-flow changes.
Sources: [The Hacker News](https://thehackernews.com/2026/11/n-able-confirms-hackers-accessed-cloud.html)

**European Commission confirms attack using the ARTEX AI tool.** The Commission says an "AI-generated cyber campaign" detected on 22 October disrupted personnel systems, including payroll and leave, for more than 10 days; CERT-EU reportedly identified ARTEX. It says it has found no broad data breach of staff.
Sources: [The Record](https://therecord.media/european-commission-confirms-cyberattack-using-ai), [Infosecurity](https://www.infosecurity-magazine.com/news/commission-ai-attack-systems/)

**Transport for London breach exposes 265,000 Oyster photocard customers.** Names, phone numbers and email addresses were exposed and TfL's own mail system was used to send fraudulent emails; the photocard site is offline.
Sources: [BleepingComputer](https://www.bleepingcomputer.com/news/security/transport-for-london-breach-exposes-265-000-oyster-card-users-data/), [Infosecurity](https://www.infosecurity-magazine.com/news/tfl-customers-personal-data-exposed/)

**The Gentlemen list NVIDIA; NVIDIA points to a partner incident.** The ransomware group has put NVIDIA on its leak site with a deadline of 28 November but no evidence; NVIDIA says it has found no compromise of its own systems and is investigating an incident that may have affected a third-party partner.
Sources: [BleepingComputer](https://www.bleepingcomputer.com/news/security/nvidia-investigating-gentlemen-ransomware-breach-claims/), [Cyber Daily](https://www.cyberdaily.au/security/14466-breached-the-gentlemen-ransomware-group-claims-nvidia-hack)

**UPS management software abused to run code on a domain controller.** Symantec saw an attacker use CyberPower PowerPanel Business's power-event scripts, which run as SYSTEM, to copy the Active Directory database and plant an implant. Restrict PowerPanel's web console and review configured shutdown scripts.
Sources: [Infosecurity](https://www.infosecurity-magazine.com/news/ups-software-abused-domain/)
